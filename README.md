# Планшет 192.168.1.83

Безпечна оптимізація Android-планшета по Wi-Fi. Профіль скорочує анімації, вимикає постійне сканування Wi-Fi і Bluetooth, вмикає адаптивну батарею, чистить кеш програм, ставить у чергу оптимізацію запуску і надсилає обслуговування сховища.

Програми, фото, облікові записи й системні сервіси не видаляються. Планшет не скидається.

Оптимізатор має працювати на комп’ютері в тій самій мережі, що й планшет. З віддаленої машини адреси `192.168.1.83` не видно.

## Підготовка планшета

1. Налаштування → Про планшет → сім натискань на «Номер збірки».
2. Для розробників → увімкнути «Бездротове налагодження».
3. На Android 11 і новіших найпростіше сполучити через QR: у веб-інтерфейсі «Сполучити через QR», на планшеті — «Сполучити пристрій через QR-код».
4. Альтернатива: код сполучення (порт коду і порт підключення різні) або на Android 10 і старіших один раз з кабелем `adb tcpip 5555`.

Потрібен [Android Debug Bridge](https://developer.android.com/tools/adb) у `PATH`.

```bash
sudo apt install adb
```

## Запуск

```bash
npm install
npm run dev
```

Відкрийте http://127.0.0.1:43117. Натисніть «Сполучити через QR», на планшеті відкрийте «Сполучити пристрій через QR-код» і наведіть камеру на код. Після сполучення зчитайте стан і застосуйте профіль.

Те саме з термінала через QR:

```bash
npm run optimize -- --qr
```

Або вручну, порт підставте свій:

```bash
npm run optimize -- --host 192.168.1.83 --port 41555
```

Сполучення кодом:

```bash
npm run optimize -- --host 192.168.1.83 --pair-port 37123 --code 123456 --port 41555
```

Повернути анімації, сканування і ліміт процесів:

```bash
npm run optimize -- --host 192.168.1.83 --port 41555 --restore
```

Подивитись команди, не торкаючись планшета:

```bash
npm run optimize -- --dry-run
```

Додаткові кроки, вимкнені за замовчуванням, бо змінюють поведінку сповіщень і екрана:

```bash
npm run optimize -- --with-memory-limit --with-screen-timeout
```
